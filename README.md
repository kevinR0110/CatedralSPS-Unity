## Como ejecutar
1. Descargar el build desde la seccion Releases del repositorio (o la carpeta entregada).
2. Descomprimir el .zip.
3. Ejecutar `CatedralSPS.exe`.

## Como abrir el proyecto en Unity
1. Clonar el repositorio (`git clone <URL>`). Es necesario tener Git LFS instalado.
2. Abrir Unity Hub -> Add -> seleccionar la carpeta del proyecto.
3. Abrir la escena `Assets/Scenes/Catedral_Main`.
